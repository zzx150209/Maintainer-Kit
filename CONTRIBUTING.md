# Contributing

Use Python 3.10 or later. Follow the README quick start and run `PYTHONPATH=src python3 -m unittest discover -s tests -v` before proposing changes.

For bug reports, include your Python version, a minimal directory layout, the command, expected behavior and actual output. Remove private paths and sensitive content.

Keep scanning offline, read-only and dependency-light. New checks should provide evidence, state their limitations and include boundary tests. Propose substantial new behavior in an issue before implementation. Do not submit fabricated adoption, usage or sponsorship claims.
