# Community conduct

Treat participants respectfully. Discuss the work, give actionable feedback and assume differing experience levels. Harassment, threats, discrimination, doxxing and spam are not welcome in issues, pull requests or other project spaces.

The repository maintainer, https://github.com/zzx150209, moderates these spaces and may hide or remove abusive content, close disruptive discussions or restrict participation. Enforcement depends on context and severity; this project does not promise around-the-clock moderation.

For a concern that should not be public, contact the maintainer through the GitHub profile to arrange a private channel before sharing sensitive details. If the concern involves the maintainer, GitHub's platform reporting tools remain available.
