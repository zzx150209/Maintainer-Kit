# Roadmap

## Delivered in 0.2.0

Offline checks, evidence paths, portable JSON/Markdown reports, custom paths, optional checks, regression baselines, a composite Action and English/Chinese documentation.

## Delivered in 0.3.0

Explicit offline shared community-file fallback with local precedence, source-labeled evidence, portable root labels and CLI/Action support.

## Next candidates

1. Nested issue and pull-request templates with bounded traversal and symlink tests.
2. Content validation as a separate opt-in layer, clearly distinguished from presence checks.
3. Feedback from real maintainers about false positives and useful missing checks.

These are proposals, not promises or evidence of existing demand. Favor a small reliable rule set over broad, noisy scoring.
