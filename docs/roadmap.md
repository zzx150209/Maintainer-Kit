# Roadmap

## Delivered in 0.2.0

Offline checks, evidence paths, portable JSON/Markdown reports, custom paths, optional checks, regression baselines, a composite Action and English/Chinese documentation.

## Next candidates

1. GitHub organization defaults: explicit local fallback directory, preserving offline behavior.
2. Nested issue and pull-request templates with bounded traversal and symlink tests.
3. Content validation as a separate opt-in layer, clearly distinguished from presence checks.
4. Feedback from real maintainers about false positives and useful missing checks.

These are proposals, not promises or evidence of existing demand. Favor a small reliable rule set over broad, noisy scoring.
